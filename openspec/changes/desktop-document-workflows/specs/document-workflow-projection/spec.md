# F014 三场景工具投影与项目无损回归

## Purpose

为 dsh-structured-document 的三场景工具投影与项目无损回归维护唯一可编辑的行为与验收规格，保留原编号 F014，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## ADDED Requirements

### Requirement: F014 三场景工具投影与项目无损回归

系统 SHALL 按下列完整场景落实三场景工具投影与项目无损回归的预期、边界与验收。本节为原有待实现设计的格式迁移，尚未获得实施批准，不作为现有能力。

#### Scenario: F014-S01 场景与预期

- **WHEN** Agent 在三种场景读取、修改或创建文档
- **THEN** 场景与预期：保留 17 工具、三模板、事务与保存边界；模型原生调用和程序化调用均取得实际正文、候选、路径、版本和保存结果，项目规则由工作区 Skill 决定。

#### Scenario: F014-S02 边界与异常

- **WHEN** Agent 在三种场景读取、修改或创建文档
- **THEN** 边界与异常：业务进展叙述与百分比不同，任务排期由 WBS 维护；文档内核不重写项目 Excel 或周报数据；正文已保存而登记／打开／sidecar 失败不得说完全未保存。

#### Scenario: F014-S03 验收条件

- **WHEN** Agent 在三种场景读取、修改或创建文档
- **THEN** 验收条件：会议、project、thinking 无损读取；真实项目副本的编号与标签正文保持，批量修改／外部变更／重复请求／撤销回归；固定目标、真实 revision 与模型输出一致。

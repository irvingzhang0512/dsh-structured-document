# F012 宿主固定绑定所有权

## Purpose

为 dsh-structured-document 的宿主固定绑定所有权维护唯一可编辑的行为与验收规格，保留原编号 F012，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## ADDED Requirements

### Requirement: F012 宿主固定绑定所有权

系统 SHALL 按下列完整场景落实宿主固定绑定所有权的预期、边界与验收。本节为原有待实现设计的格式迁移，尚未获得实施批准，不作为现有能力。

#### Scenario: F012-S01 场景与预期

- **WHEN** 工作台请求宿主固定绑定或释放所有权
- **THEN** 场景与预期：文档服务提供 getBindingState 与 claimBinding／lease，让工作台按会话持有固定文档或固定空态；隐式浏览跟随不能修改 owner 的目标。

#### Scenario: F012-S02 边界与异常

- **WHEN** 工作台请求宿主固定绑定或释放所有权
- **THEN** 边界与异常：每会话至多一个有效 lease；旧无 lease 隐式／外部改绑拒绝，显式文档创建仍按用户请求并由工作台登记。释放不补执行旧浏览消息，失败绑定保留原状态；工作区真实路径围栏保持。

#### Scenario: F012-S03 验收条件

- **WHEN** 工作台请求宿主固定绑定或释放所有权
- **THEN** 验收条件：来源浏览与两个会话不串目标；固定空态不回静态兜底；重复 claim／失效 lease 拒绝；绑定失败与释放清理可观察；不再依赖浏览器 window 标记实现保护。

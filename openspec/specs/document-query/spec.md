# F002 查询、定位与中文指代

## Purpose

为 dsh-structured-document 的查询、定位与中文指代维护唯一可编辑的行为与验收规格，保留原编号 F002，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F002 查询、定位与中文指代

系统 SHALL 按下列完整场景落实查询、定位与中文指代的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F002-S01 场景与预期

- **WHEN** 用户查询、选择或用中文指代文档节点
- **THEN** 场景与预期：读取文档与大纲、搜索节点、选择／读取选择；支持节点 id、标题、@root、@selected、@last_edited、@last_created 等引用。

#### Scenario: F002-S02 边界与异常

- **WHEN** 用户查询、选择或用中文指代文档节点
- **THEN** 边界与异常：同名多候选要反馈歧义，不随机选；删除节点清理相关指针；无选择时不能猜测“这个”。

#### Scenario: F002-S03 验收条件

- **WHEN** 用户查询、选择或用中文指代文档节点
- **THEN** 验收条件：选择后指代可命中；同名返回候选；删除后旧选择引用明确失败。

# F004 撤销与单调版本

## Purpose

为 dsh-structured-document 的撤销与单调版本维护唯一可编辑的行为与验收规格，保留原编号 F004，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F004 撤销与单调版本

系统 SHALL 按下列完整场景落实撤销与单调版本的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F004-S01 场景与预期

- **WHEN** 用户修改、保存或撤销文档
- **THEN** 场景与预期：默认自动保存时，成功修改与撤销均增加 revision；undo 恢复前一个快照，节点 id 分配保持单调。

#### Scenario: F004-S02 边界与异常

- **WHEN** 用户修改、保存或撤销文档
- **THEN** 边界与异常：撤销历史在宿主内存，重启不保证保留；没有 redo 承诺；不可复用已经发出的 id 或回退 revision。autoSave 关闭时普通修改只改变内存，版本在后续保存时推进，不能将默认模式的每步写盘规则套用到关闭模式。

#### Scenario: F004-S03 验收条件

- **WHEN** 用户修改、保存或撤销文档
- **THEN** 验收条件：撤销后内容恢复但 revision 增加；再新增 id 不与已删除节点冲突；无历史时明确反馈。

# 使用手册

面向最终用户(在 DSH 中用中文操作结构化文档)与集成方。

## 基本约定

- 插件操作的是**当前文件**(运行环境注入);没有当前文件时工具会提示先打开文档;
- 修改默认**自动保存**(写盘成功才计入版本;失败整体回滚);
- 每一步修改都可 **撤销**;节点 ID 在移动、改名后保持不变;
- 结果里的中文 `message` 直接面向你;`node_007` 这类 ID 出现在结果里,直接说"node_007"也能引用。

## 三类文档

| 模板 | 适合 | 角色 |
|---|---|---|
| meeting 会议纪要 | 周会、评审、复盘 | 议题 / 讨论 / 问题 / 结论 / 决定 / 待办 |
| project 项目管理 | 项目、迭代、任务 | 目标 / 关键结果 / 阶段 / 任务 / 问题 / 风险 |
| thinking 思路整理 | 汇报、方案、头脑风暴 | 主题 / 问题 / 想法 / 方案 / 疑问 / 结论 |

待办 / 任务支持属性:负责人、状态(未开始 / 进行中 / 已完成 / 已取消)、截止时间;项目任务另有进度(0-100,说"50%"即可)。

## 常用说法

### 看结构
- 「看看现在的结构」「这个文档有哪些部分」
- 「找一下热红外相关的节点」「有哪些待办」「负责人是张三的任务」

### 定位
- 「进入9月验证这一部分」「选中当前算法问题」
- 「现在选中的是哪个」「刚才改的是哪条」

### 修改
- 「在当前节点下面增加一个任务:采集热红外数据」
- 「加一个待办,负责人张三,周五完成」(一次给全,不用拆两步)
- 「把项目目标改成……」「这一条的说明补充一句」
- 「这一条删掉」「这个不要了」
- 「把这个移动到9月计划下面」「把第三条放到第一条」「这一条往上移」
- 「这条不是讨论,改成结论」「刚才这一条改成方案」

### 属性与状态
- 「负责人改成李四」「状态改成进行中」「截止时间改成周五」「进度改成50%」

### 反悔
- 「撤销」「不对,恢复」「刚才那步不要」(可连续撤销多步)

## 指代表

| 你说 | 指向 |
|---|---|
| 这个 / 这一条 / 当前(的) | 当前选中的节点 |
| 刚才改的 / 刚刚修改的那条 | 最近修改的节点 |
| 刚加的 / 刚才新增的那个 | 最近新增的节点 |
| 上一条 / 前面那条 | 它的前一个兄弟 |
| 下一条 / 后面那条 | 它的后一个兄弟 |
| 第二个 / 第 N 个 / 最后一个 | 同名节点中的序号 |

## 歧义时会发生什么

文档里有多个同名(或标题都包含关键词)节点时,助手**不会替你猜**,而是列出候选:

```
候选节点:
  1. 防干烧项目周会 › 议题 › 讨论热红外方案(ID:node_003)
  2. 防干烧项目周会 › 决定 › 讨论热红外方案(ID:node_005)
```

回答「第二个」或直接说 ID 即可。

## 集成方须知(Current File Integration)

插件通过 `CurrentFileProvider` 接缝获取会话的当前文件;提供者返回空时工具返回 `NO_CURRENT_FILE`。插件不做文件树 / 选择 / 切换——这部分由 Controller / Sidebar 协同(接口与 TODO 见 [架构](architecture.md#7-当前文件集成current-file-integration))。调试可在配置里静态指定 `currentFile`。

## 故障与恢复

| 现象 | 原因 | 处理 |
|---|---|---|
| `SAVE_FAILED` | 磁盘 / 权限 / 文件被占用 | 文档已回滚到操作前;排除后重试即可 |
| 文件在外部被改动 | 编辑器 / 其他工具修改了文件 | 下一次操作自动以磁盘为准重新装载(ID 会重新分配) |
| `<file>.sdoc.json` 损坏 | 误删 / 手改 | 删除 sidecar 即可;文档内容无损,仅跨会话 ID 延续失效 |
| 撤销栈为空 | 没有可撤销的操作 | 如实提示 |
